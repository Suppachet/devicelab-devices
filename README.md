# DeviceLab device list

`devices.json` is the list of phones, tablets and computers that DeviceLab (a multi-device web testing browser for
Windows) shows in "Choose the screens to show", with their screen sizes in CSS pixels, pixel ratio, operating system
and the ready-made device sets. DeviceLab's **Update the device list** button fetches this file, so new phones appear
without installing a new DeviceLab.

This repository holds only that list: no program code and no personal data.

รายการรุ่นมือถือ แท็บเล็ต และคอมที่ DeviceLab ใช้ในหน้า "เลือกเครื่อง" (ขนาดจอ ความละเอียด ระบบ และชุดเครื่องสำเร็จรูป)
ปุ่ม **อัปเดตรายการเครื่อง** ใน DeviceLab โหลดไฟล์นี้ คลังนี้มีแค่รายการเครื่อง ไม่มีโค้ดโปรแกรมหรือข้อมูลส่วนตัว
